## 本次新增

- 保留原 `index.html` 為 `index_original.html`。
- 新版 `index.html` 擴充為 46 張，加入通報紀錄、資訊邊界、人際壓力、行政協作、案例拆解、現場風險清單與結尾回饋。
- 新增 `assets/visuals/`，放置 10 張 AI 主視覺。
- 新增 HTML/CSS 可編輯文字頁：文字沒有燒進圖片。

## 設計原則

- 既有頁面能用者保留。
- 新增頁面沿用深藍、米白、大留白、低彩度馬卡龍資訊卡。
- 圖片作為氛圍，不搶文字。
- 投影與拍照可讀性優先。

## 操作

直接開啟 `index.html`，或部署到 GitHub Pages。

鍵盤：
- ← → / Space 換頁
- N 講者備忘
- G 總覽
- D 統計頁
- R 重新同步互動題
- P 列印
