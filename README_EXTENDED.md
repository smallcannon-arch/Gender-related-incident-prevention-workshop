# 校園性別事件講座延伸版 v0.7

本版重點：回到整體講座大綱後，重新整理「研習地圖」與「現場處理線」兩種圖像系統，避免流程概念互相干擾。

## 架構原則

1. **研習地圖**：只表示今天課程怎麼走。
   - 開場 → 辨識 → 接住 → 紀錄 → 協作 → 演練 → 帶走
   - 只在大章節第一頁出現。

2. **現場處理線**：只表示學生開口後第一線怎麼做。
   - 學生開口 → 接住情緒 → 確認安全 → 避免追問 → 客觀紀錄 → 通報窗口 → 交給制度
   - 不再和研習地圖同頁混用。

3. **行政協作圖**：改為「接力分工」，不再用線性流程圖呈現，避免與現場處理線混淆。

## 視覺調整

- 流程圖不再使用穿過卡片的長線。
- 箭頭改為獨立欄位，避免線條穿越節點。
- 色塊改為穩定中性色；不再每一格用過多顏色。
- 只在章節第一頁保留研習地圖，一般內容頁不顯示。
