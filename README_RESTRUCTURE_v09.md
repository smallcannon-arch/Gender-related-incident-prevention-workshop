# v0.9 重構版說明

本版依「從學生開口，到學校系統接手」重新整理簡報脈絡。

## 主要調整

- 不再硬守前版底圖與零散流程圖，改為一致頁型。
- 核心現場處理線提前到開場後，且全場只保留一條：
  學生開口 → 接住情緒 → 確認安全 → 避免追問 → 簡要留痕 → 通報窗口 → 制度接手。
- 「辨識」改為事件敏感度地圖，不再像現場第一步。
- 「紀錄」統一改為「簡要留痕」，避免誤導第一線自行調查。
- 案例一、案例二、案例三均使用一致小標籤與三段式格式。
- 行政協作改為接力分工，不再呈現成第二條流程線。
- 互動題保留原資料屬性與同步機制。

## 建議檢查

1. 現場處理線是否比前版更穩定。
2. 案例標籤是否一致。
3. 文字量是否適合 90 分鐘研習。
4. 是否需要壓縮到 42 頁以內。
